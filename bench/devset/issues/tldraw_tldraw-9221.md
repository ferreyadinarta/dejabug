# Toolbar dragging incorrectly selects pen tool

### What happened?

Dragging out a pen-drawn element from the toolbar (e.g. the cursor or hand/pan tools) will select the pen tool while the drag is happening. Upon releasing the drag, the cursor tool gets correctly (re-)selected.

### How can we reproduce the bug?

https://github.com/user-attachments/assets/58b23239-dee2-4e8f-a33d-7ce23af0004f

### What browsers are you seeing the problem on?

Chrome

### Where did this happen?

tldraw.com
